##LMSC-216 Final Project Documentation File

For this project, I created an early-internet style personal archive/portfolio website from sratch using HTML and CSS. While it is certainly a very simple website, I am very satisfied with how it turned out, and accomplished everything I had outlined in the project propsal.
First, I revisited the class documents from when we set up a website through GitHub, and took myself through that process again. I spent some time decoding the HTML pages of the example websites I sited, and looked through a lot of online resources to get a grasp of HTML and CSS. I started by making the homepage, which would contain only four links, (audio, images, video, text). I tried many different ideas for the layout of the homepage before landing on the final one, but I started with a placeholder, by just making sure I could link to the other pages and place a single image on the home screen. Once I had gotten this far and was starting to understand the workflow, I ran into some issues that I still don't really understand with GitHub, which we fixed together during class.
It was surprisingly easy to create the grid of beetles, but what I had to spend the most time on to make work correctly was the Beetle Buttons that link to the other pages. They are overlayed images on top of the background grid, and it took a lot of fiddling with CSS to get the images to align perfectly with the other tiles and remain so even when changing the browser size.
Once the home page was working correctly, I finally started to feel like it was coming together, and once I started filling the pages with media, it was basically done. I created a text category, however I realized too late that I haven't really written anything that I would like to share. Yet. I plan on fleshing this website out further in the future, and to continually update it with more images, music, videos, maybe even poems.
